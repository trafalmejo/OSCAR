Quick reference

QLab over OSC

QLab listens on port 53000; nothing to switch on. Set every widget here to the Mac running QLab, port 53000. Every key sends its address bare, once, when pressed.

GO
/go
Sent once, bare, when pressed: the next cue in the list goes. Nothing is sent when it is let go.
STOP
/stop
Stops everything, bare, once.
PAUSE / RESUME
/pause /resume
Bare, once each.
PREV / NEXT
/playhead/previous /playhead/next
Moves the playhead. Bare, once each.
RESET
/reset
Resets the workspace: the playhead to the top, every cue stopped.
PANIC
/panic
Fades everything out over the workspace's panic time. Twice, quickly, is a hard stop.
START Qn
/cue/n/start
Starts that cue number, wherever the playhead is. The number is in the address, so no argument.

A workspace with a passcode wants /connect <passcode> first. QLab replies on port 53001; nothing here listens, because a GO button has no state to follow.
