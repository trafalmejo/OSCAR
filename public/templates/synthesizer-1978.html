Owner's manual

Every control speaks MIDI

Channel 1, to the first MIDI output this computer has. Select a control in the editor to send it to another port or channel, or to switch OSC on as well.

THE KEYS
Notes 48 to 72, channel 1
Two octaves and a top C, C3 to C5. A key sends note on at velocity 127 while it is held and note off when it is let go. The computer keyboard plays them too: Z to M for the lower octave, Q to I for the upper, the rows above them for the black keys.
SUSTAIN
Control change 64
It latches: 127 holds every note that is sounding, 0 lets them go.
PITCH
Pitch bend
The whole range, centre 8192. Let go and it springs back to the middle and says so.
MOD
Control change 1
0 to 127, the modulation wheel.
FILTER
Control change 74 and 71
Cutoff (brightness) and resonance, 0 to 127.
ENVELOPE
Control change 73, 75, 72
Attack, decay and release, 0 to 127.
VOLUME
Control change 7
The channel volume, 0 to 127.
PROGRAM
Program change
Picks General MIDI sounds, so the synthesizer built into Windows plays them as named. A synth of your own may call those numbers something else.

To play a DAW on this computer, make a port with loopMIDI, pick it under Out port on each control, and pick it as the DAW's input. Delete these notes from the layout before the show.
