Operating instructions

Your new remote control unit

Point the unit at anything that understands OSC. Each key sends to the address below. Select a key in the editor to aim it somewhere else.

POWER
/tv/power
1 on, 0 off. It stays lit while the set is on.
0 to 9
/tv/digit/0 ... /tv/digit/9
1 while the key is held, 0 when it is let go.
CH
/tv/channel/up /tv/channel/down
1 while held.
VOL
/tv/volume/up /tv/volume/down
1 while held. Hold it and count, as the set did.
MUTE
/tv/mute
1 muted, 0 not.
TV / VCR / CABLE
/tv/source
1, 2 or 3, as a whole number.
VCR keys
/vcr/rew /vcr/play /vcr/ff /vcr/stop /vcr/rec
1 while held. REC is red for a reason.

Keep this leaflet. Delete it from the layout when the unit goes to the sofa: on a phone the handset is all you need.
