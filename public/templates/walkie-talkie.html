Radio procedure

Each control sends OSC to the address below. Select one in the editor to aim it somewhere else.

PUSH TO TALK
/radio/ptt
1 while held, 0 when let go. Nothing latches: let go and you are off the air.
CHANNEL
/radio/channel
1 to 22, as a whole number.
CALLSIGN
/radio/callsign
Type it and press Enter. It is sent as text.
CALL
/radio/call
1 while held.
MON, SCAN, BEEP
/radio/monitor /radio/scan /radio/beep
They latch: 1 on, 0 off.
VOL, SQL
/radio/volume /radio/squelch
0 to 1.
Signal bars
/radio/signal
These listen. Send 0 to 1 and the bars climb.

Delete this card from the layout before going into the field: on a phone the handset is all you need. Out.
