Owner's leaflet

Music, wherever you walk

Each control sends OSC to the address below. Select one in the editor to aim it somewhere else.

PLAY
/cassette/play
It latches, as the real key did: 1 down, 0 up. The reels turn while it is down.
STOP, REW, FF
/cassette/stop /cassette/rew /cassette/ff
1 while held. The winding keys hurry the reels.
HOTLINE
/cassette/hotline
1 while held. On the real one it let you talk over the music.
VOLUME L, R
/cassette/volume/left /cassette/volume/right
0 to 1. It had one for each ear.
TAPE
/cassette/tape
1 normal, 2 chrome, 3 metal, as a whole number.
BATT
/cassette/battery
This listens. Send 0 to 1 and the lamp strip fills.

Delete this leaflet from the layout when the player goes in a pocket.
