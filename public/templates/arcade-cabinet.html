Instruction card

How to play

Each control sends OSC to the address below. Select one in the editor to aim it somewhere else.

JOYSTICK
/arcade/stick
Two numbers, x then y, each from -1 to 1. It stays where you leave it.
BUTTONS 1 to 6
/arcade/button/1 ... /arcade/button/6
1 while held, 0 when let go.
COIN
/arcade/coin
1 while held. The screen counts the credit.
1P START
/arcade/start
It latches: 1 game on, 0 game over.
ENERGY
/arcade/energy
This listens. Send 0 to 1 and the bar on the screen fills.

Delete this card from the layout when the cabinet goes on the floor.
