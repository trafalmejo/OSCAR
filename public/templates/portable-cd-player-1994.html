Do not run with this player

Each control sends OSC to the address below. Select one in the editor to aim it somewhere else.

PLAY / PAUSE
/cd/play
It latches: 1 playing, 0 paused. The disc turns while it is on.
STOP, PREV, NEXT, OPEN
/cd/stop /cd/prev /cd/next /cd/open
1 while held.
TRACK
/cd/track
1 to 99, as a whole number. Type it, or use the arrows.
SHUFFLE, REPEAT, BASS, ANTI-SHOCK
/cd/shuffle /cd/repeat /cd/bass /cd/antishock
They latch: 1 on, 0 off. Each lights its word on the display.
VOLUME
/cd/volume
0 to 1.
HOLD
/cd/hold
0 or 1, as a whole number.
Battery
/cd/battery
This listens. Send 0 to 1 and the battery on the display fills.

Delete this booklet from the layout when the player goes in a bag.
