OSCAR

Direct drive turntable · SL-72

Sleeve notes

Handle by the edges

Each control sends OSC to the address below. Select one in the editor to aim it somewhere else.

START · STOP
/turntable/start
It latches: 1 turning, 0 stopped. The label and the strobe dots turn with it.
45
/turntable/45
It latches: 1 for 45 rpm, 0 for 33 1/3. The platter turns faster to match.
CUE
/turntable/cue
It latches: 1 lowers the arm onto the record, 0 lifts it back to its rest.
The record
/turntable/scratch
Two numbers, x then y, each from -1 to 1: where a finger is on the vinyl. The angle is atan2(y, x); follow it and you have a scratch.
PITCH
/turntable/pitch
-8 to 8 per cent.
ANTI-SKATE
/turntable/antiskate
0 to 3.
OUTPUT
/turntable/level
This listens. Send 0 to 1 and the lamps light.

Delete these notes from the layout when the needle goes down.
